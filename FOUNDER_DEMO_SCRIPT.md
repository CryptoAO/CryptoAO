# SAFELEARN Founder Demo Script (3–5 minutes)

## Audience A: Parents (Trust + Safety)
**Goal:** Show safety, calm guidance, and evidence of learning without transcripts.

**Click path:**
1) **Demo Login → Select Child**
2) **Kid Chat → Quick Prompt → Socratic hint**
3) **Quest Runner → Complete Quest → World Unlock**
4) **Learning World → Tap unlocked item**
5) **Parent Dashboard → Safety Audit → Sessions Summary → Reset Demo**

**Talking points:**
- **Walled Garden:** All responses are grounded in our Learning Vault. No web browsing or links.
- **Defense-in-depth:** Input guard + output guard + refusal templates keep content kid-safe.
- **Socratic-first:** Spark gives hints before answers and always asks a question or offers choices.
- **Learning World:** Mastery unlocks meaningful items—learning is the reward.
- **Evidence without transcripts:** Parents see mastery deltas and session summaries, not raw chat.
- **Quests Only lock:** Repeated unsafe prompts trigger a gentle “quests only” mode.

**Wow moments to trigger live:**
1) Ask a math question in Kid Chat → see Socratic hint + choices.
2) Complete a quest → see the World Unlock celebration.
3) Attempt an unsafe prompt → see calm redirect + safety category log (no unsafe words echoed).

## Audience B: Investor/Partner (Differentiation + Defensibility)
**Goal:** Show product loop, safety moat, and learning evidence.

**Click path:**
1) **Demo Login → Select Child**
2) **Kid Chat → Quick Prompt → Socratic hint**
3) **Quest Runner → Complete Quest → World Unlock**
4) **Learning World → Tap unlocked item**
5) **Parent Dashboard → Safety Audit → Sessions Summary → Reset Demo**

**Talking points:**
- **Walled Garden:** No external links or web browsing—responses are grounded in a vetted Learning Vault.
- **Safety moat:** Input + output guards with lockout for repeated unsafe attempts.
- **Socratic-first pedagogy:** Guides discovery and reinforces mastery over rote answers.
- **Intrinsic motivation:** Learning earns Magic Haven upgrades, not the reverse.
- **Outcome evidence:** Session summaries show skills practiced and mastery change without transcripts.
- **Swap-ready architecture:** Mock services now; vector DB, LLM, and Supabase can drop in later.

## One-page Demo Checklist

### Pre-demo setup
- Run: `./run_demo.sh`
- PIN: `1234`
- If needed, tap **Reset Demo** in Parent Dashboard.

### Failure fallback
- If backend is unreachable, the app switches to Offline Adventure mode.

### What to avoid saying
- Avoid medical/legal claims.
- Avoid absolute statements like “100% impossible to bypass.”
- Say “defense-in-depth” and “designed for safety” instead.
